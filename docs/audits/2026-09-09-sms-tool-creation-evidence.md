## Historical defects and corrections

The earlier checkpoints below document the repairs that led to the current contract. In particular, migration 219 now owns atomic commercial pricing/save; the older per-row helper evidence does not describe its transaction.

| Problem and evidence | Underlying cause | Required fix implemented |
|---|---|---|
| Repeating an air-conditioning request after tenant rates changed returned the original token with newly calculated money. The actual recommendation POST reproduced the mismatch. | The save helper reused an existing row, while the route returned the newly calculated recommendation. Plan/location/design fields could also describe a different result. | Both recommendation and plan POSTs look up the owned request before pricing or provider work. An input fingerprint includes the tool kind, validated input and, for plans, actual file bytes. The complete original response context and recommendation are persisted together. Replays return that saved response. Concurrent incompatible requests and unprovable legacy receipts return 409; lookup failure returns 503. |
| Commercial-painting save retries created two intakes and quotes after a resolved extraction-metadata update error. | The best-effort `sheets_used.saved_quote` marker was the only reuse anchor. Random row IDs could not recover a committed save when that marker was missing. | Stable tenant/run/extraction/pricing-pass row IDs, conflict-ignore writes and owned readback preserve the winning quote and random public token. UUID case variants use the same identity. A failed or unobservable write returns no link. |
| A saved commercial tender could be associated with a different source or customer if its projection pointed at another owned quote. | Checking tenant ownership alone does not prove which pricing pass generated the quote. | Readback verifies the owned intake's trade, run, extraction, pricing timestamp and supplied customer phone. Missing legacy provenance or conflicting associations return an actionable 409 and leave the existing quote unchanged. No association is guessed from a name or address. |
| A successful commercial save lost the customer's details when its later caller update failed. | Intake persistence and customer attachment were separate operations; the latter resolved error was unchecked. | Customer details and source provenance are part of the initial intake write. Later projection failure cannot remove them. |
| A real commercial tender's printed footer used the internal engine origin. | PDF HTML composed its footer directly from `APP_URL`. | The actual tender HTML now uses the shared canonical public URL helper. PDF generation remains optional and never releases a customer quote. |
| Creation-helper changes could escape website/service release compatibility checks. | Recommendation, plan and commercial pricing/save routes were absent as mandatory website dependency roots. | All four routes are mandatory roots. Their full local import closures include replay and persistence helpers; the real verifier rejects changed helpers and manifests missing a root. |
| Saving a valid commercial takeoff without an optional height returned 422 after successful pricing. | The real pricer returned an own `height_m: undefined` property. JSONB/PostgREST removes it, so a strict comparison rejected the unchanged saved BOM. | Normalise the authoritative recalculation through the same JSON representation before comparison. Tenant, finite-price and labour-rate validation still precede the equality check. The actual failing route reproduction is retained in `commercial-json-repro.log`; the 17-route regression and independent review pass after the fix. |
| Repricing an explicitly approved commercial tender changed the amount on its existing public token without another approval. | The price route overwrote the extraction read by the public run page; `released_at` remained set. A real price→save→release→reprice test exposed the old 2481.95 total changing to 4780.95. | Migration 211 protects published price-bearing rows and run identity. The actual price API rejects a released run with 409, checks guard readiness, and confirms its writes. All 32 real SQL guard cases pass. The composed journey retains the original 2481.95 total after tenant rates change, with 211/212 active; changed pricing requires a new tender. |
